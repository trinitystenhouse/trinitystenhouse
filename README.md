## Research

**The 20 GeV Galactic halo excess.** An independent, pixel-level reanalysis of
the halo-like excess in *Fermi*-LAT data, its dark matter interpretation, and a
programme of robustness tests against conventional explanations.
[Paper](https://arxiv.org/abs/2607.08552) ·
[Code](https://github.com/trinitystenhouse/Totani-Reanalysis) ·
[Archive](https://doi.org/10.5281/zenodo.21280724)

**Photon-dark matter scattering.** An effective-operator scan of elastic
photon-dark matter scattering, with the first operator-resolved sensitivity
estimates from the Galactic halo.
[Paper](https://arxiv.org/abs/2608.29546) ·
[Code](https://github.com/trinitystenhouse/EFT_Operator_Scan) ·
[Archive](https://doi.org/10.5281/zenodo.21703809)

I care about research code that can be trusted: pass criteria fixed before the
data are read, validation against published results, simulated-data checks,
and every quoted number traced to the output and code version that produced it.
That applies to code I write and to code written with AI agents.
